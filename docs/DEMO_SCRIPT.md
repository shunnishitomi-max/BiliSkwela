# Six-minute demo

0:00-0:30: Introduce BiliSkwela, its conversion from MeronPa, and the three team members.

0:30-1:20: Register a Staff account, sign out/in, explain password recovery and show a local reset link with a disposable account.

1:20-2:10: Staff sees read-only catalog and stock-out. Admin sees catalog actions, reports and Team access. Show an unauthorized direct request rejected by the backend.

2:10-3:30: Admin creates a temporary category, supplier and product; shows details; edits it; demonstrates server validation; deletes the unused product, then its supplier/category. Do not use seeded products with stock history for the delete demo.

3:30-4:20: Stock in and stock out; show movement author and quantity; reject an excessive stock-out; open low-stock dashboard and a print report.

4:20-5:40: Explain Fortify provider/actions; Spatie HasRoles, seeders and route middleware; React app.jsx with createInertiaApp/resolvePageComponent; root Blade directives; Inertia::render from a controller; reusable Field/Layout/Catalog components.

5:40-6:00: Show actual member-authored PRs and commit history. End with the instructor collaborator and video submission checks.

Rehearse first. Use a disposable demo database and dedicated accounts. Keep normal workflows free of console errors; intentional permission/validation demonstrations should be explained as expected denials, not runtime failures.
